## 验收方法

每项分别在明亮、暗色模式检查：先观察未聚焦外观，再用 Tab／Shift+Tab 聚焦；输入框另外用鼠标点击。预期没有额外蓝色／红色 ring、原生 outline 或仅因聚焦出现的边框变色，普通边框仍存在。菜单使用方向键切换，允许原有背景高亮；按钮使用 Enter／Space 验证操作，弹窗使用 Escape 验证关闭与焦点恢复。删除流程只需检查确认弹窗，无需实际删除数据。发送、保存及登录等有副作用动作可仅聚焦检查。

## 未挂载组件的清理

Dialog 与 Sheet 默认关闭按钮的 2px ring 和 offset 同步移除。当前设置和窄屏侧栏使用自定义 Button 关闭按钮，未启用默认按钮，因此默认按钮清理通过源码核对，不作为当前页面可见控件要求用户验收。Button 的 destructive 变体及 Input／NativeSelect／Button 的 aria-invalid ring 色也已移除，错误边框保留。
