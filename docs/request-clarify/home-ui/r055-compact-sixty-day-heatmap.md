# r055-compact-sixty-day-heatmap 需求澄清

日期：2026-08-29

## 已确认目标

首页侧栏的活跃热力图改为展示滚动的最近 60 个自然日。热力图不再显示格内日期数字、星期标签或首末日期标签，只保留按时间排列的热力方块；每天的日期与笔记数继续通过无障碍名称和悬停提示提供。方块及间距缩小为接近 GitHub contribution graph 的紧凑密度。

## 数据范围

本次只覆盖 Supabase 模式。Supabase 数据源直接读取 workspace 的全部可见笔记，前端聚合窗口从 30 天调整到 60 天即可得到真实统计。Backend 模式和 `GET /notes/stats/daily-counts` 不在本次需求范围内。

## 布局规则

60 天是需求指定的统计范围，不由布局容量决定。热力图按 GitHub 的周列方式排列：每列 7 个星期位，60 个连续自然日跨越 9 列、共 63 个位置，范围外的 3 个位置留空。方块采用紧凑的固定尺寸和间距，避免为填满 300px 侧栏而拉伸。
