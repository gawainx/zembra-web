# r055-compact-sixty-day-heatmap 需求澄清

日期：2026-08-29

## 已确认目标

首页侧栏的活跃热力图改为展示滚动的最近 60 个自然日。热力图不再显示格内日期数字、星期标签或首末日期标签，只保留按时间排列的热力方块；每天的日期与笔记数继续通过无障碍名称和悬停提示提供。方块及间距缩小为接近 GitHub contribution graph 的紧凑密度。

## 数据范围

Supabase 数据源直接读取 workspace 的全部可见笔记，前端聚合窗口从 30 天调整到 60 天即可得到真实统计。

Backend 数据源当前使用既有 `GET /notes/stats/daily-counts`，历史文档记录它返回 30 天数据。本次需求允许调整旧实现；需要确认 Backend 是否已支持返回 60 天，或将该接口扩展为可请求 60 天，以保证两个构建的数据范围一致。

## 待确认事项

热力图按连续 60 个日期排列。若 Backend 暂时不能调整，是否允许 Backend 构建先显示接口返回的 30 天真实数据与 30 个零值占位，还是必须等待 Backend 60 天接口完成后再发布。
