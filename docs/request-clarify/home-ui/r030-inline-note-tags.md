# r030-inline-note-tags 需求澄清

日期：2026-08-25

## 需求背景

首页笔记卡片的展示态将标签放入独立的块级容器，正文由另一个块级 Markdown 容器承载。因此即使正文紧跟标签，浏览器也会强制从新行开始显示。

## 已确认决策

```text
现状：[标签]
      正文

目标：[标签] 正文
```

| 决策项 | 结论 |
| --- | --- |
| 修改范围 | 仅首页 NoteCard 展示态。 |
| 布局行为 | 标签与正文首段在同一行流式排列；可用宽度不足时正文按正常文本规则续行。 |
| 标签样式 | 保持现有蓝色胶囊样式。 |
| 编辑器 | 不修改编辑态与编辑器内 tag 样式。 |
| Markdown | 保留现有 Markdown 语义和后续块级内容的换行行为。 |

## 验收标准

| 场景 | 期望 |
| --- | --- |
| 含一个或多个 tag 的普通正文 | 最后一个 tag 后的正文首段从同一行开始显示。 |
| 窄卡片 | 正文可自然折行，不溢出卡片。 |
| 含多个 Markdown 段落或块级内容 | 首段与 tag 同行，后续块级内容保持原有独立排版。 |
| 编辑笔记 | 原始 Markdown 与编辑器 tag chip 行为不变。 |
