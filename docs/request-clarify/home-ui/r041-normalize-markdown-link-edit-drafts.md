# r041-normalize-markdown-link-edit-drafts 需求澄清

日期：2026-08-27

## 需求背景

r040 已在展示态接入异常链接规整，但编辑器同步时仍以原始值覆盖规整结果；双击既有笔记会再次看到 `[标题]\([URL](URL))`。用户要求卡片立即正确渲染，并在双击编辑时展示标准 Markdown。

## 已确认决策

| 决策项 | 结论 |
| --- | --- |
| 卡片展示 | 使用用户提供的完整内容验证并立即显示标题外链。 |
| 编辑草稿 | 双击既有 note 时将异常链接规整为标准 Markdown。 |
| 保存行为 | 用户不修改内容直接提交时，也保存已规整的标准 Markdown。 |
| 规则边界 | 继续只匹配 r040 已确认的 URL 显示文本与目标 URL 完全一致的异常结构。 |

## 验收标准

| 场景 | 期望 |
| --- | --- |
| 含 `\#cuda [标题]\([URL](URL))` 的卡片 | 显示 `#cuda` chip 和标题外链，不显示方括号、转义括号或 URL 文本。 |
| 双击该卡片 | 编辑器显示 `#cuda [标题](URL)`。 |
| 直接提交 | 更新请求的 `content` 为标准 Markdown。 |
