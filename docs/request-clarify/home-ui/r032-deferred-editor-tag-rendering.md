# r032-deferred-editor-tag-rendering 需求澄清

日期：2026-08-25

## 需求背景

编辑器当前在用户输入 `#` 后的任意 tag 字符时立即显示 chip。输入过程中的 token 仍可能继续变化，提前渲染会干扰用户确认 tag 内容。

## 已确认决策

| 决策项 | 结论 |
| --- | --- |
| 触发时机 | 用户在 `#tag` 后输入空格时，才将该 tag 渲染为 chip。 |
| 输入中状态 | 未输入结束空格的 `#tag` 保持普通可编辑文本。 |
| 影响范围 | 仅编辑器内的 chip decoration。 |
| 展示态 | 卡片继续按保存 Markdown 的原始位置渲染 tag。 |
| 数据契约 | Markdown 字符串、候选菜单与保存逻辑不变。 |

## 验收标准

| 场景 | 期望 |
| --- | --- |
| 输入 `#work` | 保持普通文本。 |
| 输入 `#work ` | `#work` 渲染为 chip，末尾空格保留为正文分隔。 |
| 继续输入正文 | chip 后的正文正常输入与换行。 |
