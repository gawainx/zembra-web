# R047 笔记卡片 Markdown 外链样式

## 需求范围

笔记卡片展示态中的标准 Markdown 外链需要改为红色并带下划线。这里的红色必须使用仓库现有 Bonofix 主题色系的语义 token，禁止新增或直接写入任意颜色值。

## 范围边界

只调整 `https` 或 `http` Markdown 外链。`[[note_ref]]` 内部笔记预览和 `#tag` 标签 chip 保持现有样式与行为，不纳入本次修改。编辑器、导航、按钮及其他区域的链接也不修改。

## 验收条件

笔记卡片中的 Markdown 外链使用 `--color-field` 并显示下划线，仍在新标签页安全打开。亮色和暗色主题均由现有 token 自动适配，内部笔记预览和标签 chip 不发生视觉或行为变化。
