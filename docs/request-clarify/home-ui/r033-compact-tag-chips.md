# r033-compact-tag-chips 需求澄清

日期：2026-08-25

## 需求背景

当前编辑器 tag chip 的垂直盒子明显高于相邻正文，产生不必要空白。用户希望对齐 Bonofix 风格：tag 是紧凑的行内标记，不应像高大的按钮或 badge。

## 已确认决策

| 决策项 | 结论 |
| --- | --- |
| 收紧方向 | 优先消除纵向空白，chip 高度接近正文高度。 |
| 适用范围 | 编辑态和卡片展示态使用同一套 chip 尺寸。 |
| 调整入口 | 所有尺寸集中在 `src/styles/main.css` 的共享 tag chip 规则中，方便后续反复调试。 |
| 视觉语言 | 保持现有语义 token、蓝底白字和圆角，不新增颜色。 |

## 验收标准

| 场景 | 期望 |
| --- | --- |
| 正文内 chip | 高度接近相邻正文字高，不出现显著上下空白。 |
| 编辑器与卡片 | 使用一致的紧凑尺寸。 |
| 窄宽度 | chip 内不换行，正文继续在前后自然折行。 |
