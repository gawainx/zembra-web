# r036-theme-palette-token-system 需求澄清

日期：2026-08-25

## 需求目标

完成完整主题系统的 token 化。表面、边框、正文灰阶、蓝色、红色、黄色、成功、代码、引用、遮罩、阴影和控件前景均需经由主题 palette 与语义 token 消费，组件中不得保留物理颜色或通用颜色旁路。

## 已确认决策

| 决策项 | 结论 |
| --- | --- |
| 分层 | 物理 palette token 只在亮暗主题定义；语义 token 只引用 palette；组件只引用语义 token。 |
| 颜色依据 | 保留当前经 Logseq 与 Bonofix 校准的亮暗视觉值，不新增主观色值。 |
| 覆盖范围 | 中性表面、文本、边框、阴影、遮罩、蓝色、红色、黄色、成功、代码、引用、tag 和控件前景。 |
| 清理 | 删除组件内 `white`、`black` 与直接色值的旧路径，不保留兼容别名。 |
| 主题运行时 | 不新增主题名称、设置 UI 或运行时分支。 |

## 验收标准

| 场景 | 期望 |
| --- | --- |
| 全局 CSS | 语义 `--color-*` 不直接写物理色值。 |
| 组件 | 不出现 Tailwind `white`、`black` 或十六进制颜色。 |
| 亮暗主题 | 所有语义 token 继续有完整定义。 |
