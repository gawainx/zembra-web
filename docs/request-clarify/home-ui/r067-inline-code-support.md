# R067 行内代码支持需求澄清

## 已确认范围

用户确认仅支持行内代码，覆盖新建编辑框、NoteCard 编辑态和展示态；先写文档再实施。不新增代码块能力或语言着色。

## 目标示意

```text
Markdown：正文 `const x = 1` 正文
编辑框与卡片：正文 [const x = 1] 正文
                       等宽字体、轻底色
```

复用现有亮暗主题行内代码样式。反引号包围的内容作为代码呈现，代码中的标签文字保持字面量。粘贴仍只读取纯文本，同时识别单行单反引号代码。

## 与历史决策的关系

历史纯文本粘贴策略继续用于隔离外部 HTML 格式；本需求允许纯文本中的行内代码语法转换为代码标记。现有代码块行为不作为本次新增或调整范围。

## 补充调查与修复

用户截图显示卡片直接呈现反引号，不能以已有解析器推断实际链路正常。通过真实 Tiptap 实例复现：普通文本插入 `test`（带反引号）会输出转义反引号，导致卡片按字面量展示。共享 normalizeMarkdownSource 补充成对转义的单行反引号恢复，覆盖卡片读取与编辑草稿；因此这类成对转义在本产品中按行内代码解释。未闭合反引号保持原样；包含 fenced code 的内容保守保持既有行为。未读取截图笔记原文，不断言截图一定由该路径产生。
