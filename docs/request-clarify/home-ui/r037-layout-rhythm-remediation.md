# r037-layout-rhythm-remediation 需求澄清

日期：2026-08-25

## 目标

对 Zembra 全界面进行布局节奏整改，消除 card、编辑器、侧栏、弹窗、门禁页和通知中由父级 gap、子级 margin、容器 padding、默认 Markdown margin 与 inset shadow 叠加造成的套框感和松散感。

## 范围

整改覆盖首页、note card、编辑器、侧栏、设置弹窗、设置表单、登录与后端门禁、菜单和 Toast。色彩语义维持现有 palette 到 `--color-*` 的单向体系，本需求只新增间距、圆角和表面边框的语义规则。

## 已确认的布局责任

页面和区域容器负责区域间距；列表、表单和工具栏负责同级元素间距；card、编辑器、弹窗、菜单和通知等表面负责自身内边距与唯一边框；Markdown 负责内容块内部节奏。子组件不得通过外边距影响相邻组件，选中态不得再用 inset shadow 伪造第二道边框。

## 验收标准

相邻 note card 不再形成 border 套 border 的视觉错觉；卡片正文、列表和 Expand 的纵向节奏紧凑且清晰；所有可见表面只保留一条语义边框；组件不再散落物理间距、圆角和 inset 边框值；亮暗主题下首页、侧栏、编辑器、设置页与门禁页的层级保持一致。
