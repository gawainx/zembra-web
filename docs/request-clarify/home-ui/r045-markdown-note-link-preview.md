# r045-markdown-note-link-preview 需求澄清

日期：2026-08-27

## 需求背景

双链 hover 预览当前直接显示目标笔记的原始文本。正文中的 Markdown 标记在浮层内可见，和 note card 已有的 Markdown 展示行为不一致。用户要求预览卡片也完成 Markdown 渲染。

## 已确认决策

| 决策项 | 结论 |
| --- | --- |
| 渲染能力 | 预览复用 note card 已有 Markdown、tag 和双链处理规则。 |
| 容器语义 | 预览浮层使用块级容器承载段落、列表和代码块。 |
| UI 范围 | 保留当前定位、宽度、边框、颜色和 hover 触发行为。 |
| 数据边界 | 不调整预览加载、缓存或 Supabase 查询逻辑。 |

## 验收标准

| 场景 | 期望 |
| --- | --- |
| 预览目标正文含 `**强调文本**` | 浮层以内联强调语义展示文本，不显示 `**` 标记。 |
| 预览目标正文含列表、代码、tag 或双链 | 行为与 note card 正文一致。 |
| 加载中或加载失败 | 保留已有文本反馈。 |
