# R065 嵌套标签父级名称对齐修复

日期：2026-09-12

## 问题与原因

二级标签的父级行使用共享 `Button` 后，名称按钮继承了组件基类的 `justify-center`。该按钮作为 grid 中间列的拉伸项，占满可用宽度后将名称置于列中央；`text-left` 只影响文本属性，不能改变 flex 子项的主轴对齐。因此父级名称与左侧展开控件脱离，而标签 DTO、树构建、折叠状态、筛选和子级缩进均未发生异常。

## 实际方案

复用现有 `TagTreeItem` 和共享 `Button`，仅在父标签选择按钮补充 `justify-start`。这会覆盖共享按钮的内容居中默认值，使名称从中间列左侧开始；子标签继续沿用 `NavItem` 的 grid 布局和既有缩进。不新增组件、状态、数据模型、依赖或测试视觉断言。

## 验证边界

现有首页层级标签测试继续覆盖展开与父子筛选。此改动只调整 CSS 对齐，项目测试规则禁止断言 Tailwind class、间距或固定坐标；视觉结果由用户按确认的示意图验收。
