# R062 窄屏侧边栏浮层

日期：2026-09-05

## 已确认布局

用户确认窄屏顶部显示汉堡按钮，点击后从左侧悬浮显示侧边栏，外部以淡色遮罩覆盖；点击外部、关闭按钮或按 Esc 收起。1024px 及以上继续常驻侧边栏。

## 实际实现

复用 HomePage 现有工作区工具栏、统计、DailyNotesHeatmap、NavItem 和 SidebarSection，通过 ResponsiveSidebar 的 header 与 children 插槽组合。新组件仅负责响应式浮层状态、遮罩、焦点循环和关闭逻辑；不新增数据访问层或依赖。新文件用于隔离独立的侧栏交互状态，避免继续向页面堆叠事件处理。

侧栏保持单份内容挂载，窄屏收起时隐藏内容区域。展开时固定在视口左侧并保留原工具栏的布局占位，避免笔记区域移动。热力图跟随可用宽度计算列数；导航独立滚动。宽屏断点事件清除浮层状态。按钮补齐英文、简体中文、繁体中文可访问性文案，颜色使用现有主题 token。

## 与历史方案的关系

本需求将此前窄屏隐藏的导航和统计开放为浮层入口；历史文档保持原样，以本需求描述当前行为。

## 验证与限制

完整测试 23 个文件、143 项通过；修正测试类型后再次执行侧栏与首页定向测试。Backend 和 Supabase 生产构建通过，无超大 chunk 警告。本地开发服务器启动权限被拒绝，真实浏览器明暗主题及窄屏视觉检查未完成，等待用户验收。
