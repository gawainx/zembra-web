# R063 紧凑登录入口

日期：2026-09-05

## 确认结果

用户确认品牌与模式副标题同行，保留 Supabase 和 Backend 区分；不添加登录标题、引导说明或主题装饰。输入框使用 hint 替代可见 label，同时保留无障碍名称，两种模式同步修改。

## 实际实现

直接调整 SupabaseEntry 与 BackendUrlGate 现有视图，保留认证、连接检查、工作区加载和选择逻辑，不新增组件或数据层。使用现有 Bonofix 语义颜色、间距、圆角与控件高度 token，新增共用登录宽度 token 将两种表单收窄到 22rem。品牌使用 ℤ 与 embra 无间距拼接为 ℤembra，无障碍名称保留 Zembra；品牌与模式以不换行的横向布局呈现，邮箱提示补齐三种语言；Backend 的地址、端口与工作区选择保留原有提示与无障碍名称，刷新操作在选择框旁垂直居中。

## 与历史方案的关系

本需求替换此前品牌与模式分行、可见邮箱标签和 Backend 说明文字的布局。历史文档不修改；本次不调整主题 palette 或认证行为。

## 验证

23 个测试文件、143 项测试与 Backend、Supabase 两种生产构建通过，无超大 chunk 警告。使用现有 Supabase 开发服务检查窄屏实际页面；Backend 本轮通过既有交互测试和生产构建验证，未启动 Backend 开发服务。等待用户视觉验收。
